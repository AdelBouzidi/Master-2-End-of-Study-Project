# Automatic and Predictive Scaling Based on Kubernetes and LSTM

This repository contains the final report of my Master 2 end-of-study project focused on predictive autoscaling in Kubernetes using an LSTM Encoder–Decoder model.

The project explores the deployment of a Kubernetes-based infrastructure capable of predicting future resource consumption and proactively adjusting microservice resources through horizontal and vertical scaling mechanisms.

---

# Main Topics

- Kubernetes cluster deployment
- Predictive autoscaling
- LSTM Encoder–Decoder model
- Resource consumption prediction
- Horizontal and vertical scaling
- Monitoring and visualization with Grafana
- Time-series data collection with InfluxDB
